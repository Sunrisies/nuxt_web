# 用户头像与文章封面分离

本地 PostgreSQL 核查：`users.image` 已存在，类型为可空 character varying，当前本地用户未设置头像。沿用该字段，不增加重复字段，也不将默认头像地址写进所有用户记录。

新增后端默认头像 `/api/v1/users/default-avatar.svg`，独立 SVG 资源由 Rust 服务提供，无外部图片依赖。文章详情增加 `author_avatar`：优先使用作者 `image`，空白/缺失/不支持的地址回退默认头像。Nuxt 公共文章数据保留此字段，文章详情使用头像字段，不再将文章封面作为作者头像。通用 UserAvatar 默认来源同步调整。此默认接口可匿名访问，用户列表/资料权限保持原规则。

作者头像/用户名修改在数据库内触发公共内容版本更新，以刷新缓存中的文章作者信息。没有增加头像上传管理页面。

验证：68 项 Rust 测试，生产前后端构建，ESLint，服务端 TypeScript；真实 HTTP/浏览器检查详情接口、公共文章数据、匿名默认头像、文章头像实际解码、与封面分离及用户资料权限。仅本地部署。

补充：默认头像 API 地址绕过 Nuxt 静态 IPX，避免找不到 public 文件而返回 404。真实浏览器已确认图片完成解码；事务回滚验证头像更新会提升公共内容版本，密码字段更新不会提升，测试不保留用户数据变更。

## 默认头像外观调整

默认插画改为深蓝底、薄荷绿点缀的小宇航员；保留独立 SVG 和后端资源接口。默认 URL 增加 `?v=2` 以避免浏览器继续使用旧版头像缓存，图片 provider 同步识别带版本号的默认头像地址。用户已有自定义头像不变。生产构建、ESLint、服务端类型检查及既有图片 provider 检查通过，本地更新后真实浏览器头像显示、图片解码、公共数据和用户资料权限检查全部通过。

## 用户选定猫咪插画

采用用户选定的第三张猫咪插画，将生成图转换为 384×384 WebP（34,902 字节），最终资源保存在后端 `src/assets/default-avatar-cat.webp` 并由 Rust 提供。此图是预生成的静态默认头像，并非运行时 AI 绘图。默认地址变更为 `/api/v1/users/default-avatar.webp?v=3`；保留原 SVG 接口兼容旧链接。前端回退地址、图片 provider、显示检查同步调整。用户自定义头像仍优先。

猫咪头像本地更新后，实际 HTTP 和浏览器显示、图片解码、头像/封面分离及用户元数据访问权限检查全部通过。
