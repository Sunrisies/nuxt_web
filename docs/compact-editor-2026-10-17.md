# 紧凑编辑布局与分类默认封面

采用已选定的“紧凑单行标题”方案：后台侧栏固定，普通管理页只滚动主内容；文章编辑页占用剩余屏幕高度，顶部集中标题、设置、保存与发布，下方直接左右编辑/预览，仅两个内容区内部滚动。手机使用编辑/预览切换，操作栏适配换行。

封面改为上传优先，设置中不再要求填写地址。上传后继续使用原有七牛云流程及引用保护；可点击“使用分类默认封面”移除自定义封面引用。未上传时，后端在文章列表、详情、标签列表和写入响应中返回分类封面地址 `/api/v1/posts/category-cover/{id}.svg`。该接口生成 1200×630 SVG，以分类名称及稳定配色排版，不依赖图片生成服务；无需在七牛存放重复默认图片。

默认封面由读取时解析，不覆盖文章中已有自定义封面。分类变更后默认封面地址随之变化；分类改名后图片内容更新。接口响应要求浏览器重新验证，SVG 分类文字经过 XML 转义并限制长度，且设置 nosniff/CSP。未创建分类时先提示选择分类。

本地验收：Rust 66 项测试通过；生产构建、ESLint、服务端 TypeScript；真实浏览器覆盖长正文内部滚动、页面整体无滚动、手机/平板/电脑尺寸、默认封面预览、上传封面优先及恢复默认、图片引用保护、草稿恢复、保存发布等流程。13 项编辑器检查、8 组图片管理回归及分类封面真实 HTTP 验收通过，无页面脚本错误。仅更新本地部署，不推送或部署线上。
