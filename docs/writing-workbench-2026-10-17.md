# Markdown 写作工作台

按用户要求调整独立编辑页面：电脑和平板（768px 起）默认左右分栏，左侧编辑 Markdown，右侧实时显示渲染效果。无需点击预览按钮。手机端切换“编写内容 / 预览正文”，保留完整宽度。

工具栏的“文章设置”打开弹窗，集中编辑分类、标签、状态、封面、摘要、推荐选项及原有高级 HTML。关闭弹窗返回写作，不提交或清空表单；只有保存或发布操作会提交后端。缺少分类或标签时，保存会打开设置弹窗提示补充。

保留图片上传七牛云、草稿恢复、离开提醒、保存失败保留输入、保存后继续编辑和旧链接兼容。此次调整无后端接口变更。

验证：生产构建、ESLint、服务端 TypeScript；真实浏览器验证左右分栏坐标、默认实时 Markdown 渲染、设置弹窗及草稿恢复、上传图片、保存失败、保存草稿、发布和更新、手机预览切换、390/768/1440px 无横向溢出。12 项浏览器检查全部通过，无页面脚本错误。仅本地部署。
